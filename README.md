# Calculadora de Rendimento de Investimento (CDB)

Script em JavaScript desenvolvido para simular o rendimento mensal de um valor investido em uma aplicação de renda fixa (CDB), aplicando conceitos de estruturas de repetição e funções financeiras.

# Tecnologia Utilizada
JavaScript (ES6+)

# Foco de Carreira

Projeto voltado para o setor de Fintechs (Agibank), demonstrando aptidão com lógica de negócios financeiros e manipulação de dados monetários.
